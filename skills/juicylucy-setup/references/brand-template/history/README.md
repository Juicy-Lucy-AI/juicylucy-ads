# History — dated evidence

Rejection logs, run post-mortems, performance records: one file per event,
named `YYYY.MM.DD-<what>.md`, opening with a one-line comment that says it is
evidence, not instruction.

Anything here is a record of what was true then. A dated caveat that
contradicts `../product-truth.md` does not win; when evidence changes a rule,
the rule changes in the file that owns it and this folder keeps the reason.

This folder starts empty. Delete this file once the first record lands, or
keep it — it asserts nothing about the product either way.
