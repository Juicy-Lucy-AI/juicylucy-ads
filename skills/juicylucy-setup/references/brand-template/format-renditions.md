# <Brand> — format renditions

How this brand renders the engine's static format catalogue (the
`static-formats` skill). The engine lists its mechanisms for anyone; this file
is <Brand>'s narrowing of it — which formats are excluded outright, and the
brand-specific guardrail baked into each one that stays.

A new brand may keep this file short: **the engine's catalogue applies in
full** until there is a reason to narrow it. Add an exclusion when a format
cannot be made truthful for this product (a low-stock alert for a product
that is never out of stock, say), and a guardrail when the same rejection or
the same weak ad has come back twice.

For every entry: copy must describe only what
[`product-truth.md`](./product-truth.md) says the product does, and nothing
[`compliance-overlay.md`](./compliance-overlay.md) forbids.
